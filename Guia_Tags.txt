=======================================================
   GUIA DE FORMATAÇÃO E TAGS DO VERDANT LAUNCHER
=======================================================

No painel de Notícias do launcher (e no Supabase), você pode utilizar três tipos diferentes de formatações para deixar os cartões do jeito que quiser: Blocos de Conteúdo [], Estilos Visuais {} e Comandos de Controle %%.

-------------------------------------------------------
1. BLOCOS DE CONTEÚDO (Colchetes) [ ]
Usados para definir estruturalmente as partes do cartão.

[title] O seu título aqui [/title]
  Define o título do cartão (texto maior e em destaque).

[desc] A sua descrição aqui [/desc]
  Define o corpo/descrição principal da notícia.

[imglink] https://linkdaimagem.com/imagem.png [/imglink]
  Injeta uma imagem de capa no cartão através de uma URL externa.

[hyperlink] https://youtube.com/verdant [/hyperlink]
  Torna o cartão inteiro clicável, e, quando clicado, abre esse link no navegador do usuário. Adiciona um ícone de seta no canto da imagem.

[br]
  Adiciona uma quebra de linha (Enter).

-------------------------------------------------------
2. ESTILOS VISUAIS (Chaves) { }
Usados para estilizar palavras ou frases específicas dentro do [title] ou do [desc].
A formatação abre com o nome do estilo, por exemplo {red}, e fecha com o nome dele também {/red}. Você pode misturar estilos separando-os com hífen, ex: {red-glow}.

Cores Básicas:
  {red} Texto {/red}       -> Fica vermelho
  {green} Texto {/green}   -> Fica verde Verdant
  {blue} Texto {/blue}     -> Fica azul
  {yellow} Texto {/yellow} -> Fica amarelo
  {pink} Texto {/pink}     -> Fica rosa

Efeitos e Animações:
  {glow} Texto {/glow}         -> Adiciona um brilho brilhante envolta da cor escolhida.
  {floating} Texto {/floating} -> Faz cada letra do texto ficar pulando/flutuando.
  {rainbow} Texto {/rainbow}   -> Pinta cada letra com uma cor do arco-íris.

Exemplo de combo:
  {rainbow-floating-glow} VERDANT {/rainbow-floating-glow}

-------------------------------------------------------
3. COMANDOS DE CONTROLE (Porcentagem) %%
Usados para ditar o comportamento mecânico daquele card. Podem ser jogados em qualquer parte do texto.

%pos=X% (Exemplo: %pos=1% ou %pos=2%)
  Força o cartão a se fixar permanentemente na posição/coluna indicada (1, 2 ou 3).

%ad%
  Transforma o cartão automaticamente em um Anúncio/Patrocínio.
  Ele é fixado na coluna 3 e fica rodando em carrossel caso existam múltiplos anúncios no banco de dados.
  
%time=X% (Exemplo: %time=10%)
  Usado em conjunto com %ad%. Define o tempo (em segundos) que este anúncio ficará na tela antes de rodar para o próximo. Se não especificado, o tempo padrão é 15 segundos.

-------------------------------------------------------
Exemplo de postagem completa no Supabase:

[title]Venha jogar {green-glow}HOJE{/green-glow}![/title]
[desc]
Temos novidades incríveis te esperando.[br]
Clique aqui para conferir!
[/desc]
[imglink]https://meulink.com/imagem.png[/imglink]

%ad%
%time=10%
